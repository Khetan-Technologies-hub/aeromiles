# Handoffs

One Markdown report per finished ticket, generated from the **real git diff** by the
`/handoff` command and committed next to the code.

- **Filename:** `ticket-<issue-number>.md`
- **Purpose:** a durable, reviewable record of exactly what each ticket changed — the
  bridge between the developer's Claude Code and the Manager's review.
- The PR template links to the matching report; `/manager-review` reads it during review.
